# Range Hide — SillyTavern

Мобильное UI-расширение для скрытия от ИИ диапазона сообщений по их индексам.

## Что делает
- Поля «С какого сообщения» и «По какое сообщение».
- «Скрыть от ИИ» вызывает штатную команду SillyTavern `/hide start-end`.
- «Вернуть в контекст» вызывает `/unhide start-end`.
- Сообщения остаются в истории чата; меняется только их включение в контекст модели.
- Диапазон включительный, индексы начинаются с 0.
- Панель находится в Extensions.

## Установка через GitHub
1. Создайте репозиторий GitHub и загрузите в его корень файлы из этой папки: `manifest.json`, `index.js`, `style.css`, `README.md`.
2. В SillyTavern откройте Extensions → Download Extensions & Assets → Install extension.
3. Вставьте URL Git-репозитория и установите расширение.
4. В Extensions → Manage Extensions включите **Range Hide**.

Ручная работа через SSH/терминал и отдельный серверный плагин не требуются. Это обычное UI-расширение SillyTavern.

## Пример
Чтобы исключить сообщения с индексами 114–150 включительно, укажите `114` и `150`, затем нажмите «Скрыть от ИИ».
Чтобы вернуть сообщения, укажите тот же диапазон и нажмите «Вернуть в контекст».
